<div class="fi-project-detail"><h3>Don't Retrain, Remix: Adaptation of Web Agents using Mixture Hypernetworks</h3><p class="fi-project-summary">WebMix combines learned LoRA adapters using a mixture hypernetwork, helping web agents adapt to unseen domains and changed interfaces without retraining.</p><figure><a href="{{ '/images/webmix-overview.png' | relative_url }}" aria-label="View the full WebMix method overview"><img src="{{ '/images/webmix-overview.png' | relative_url }}" width="2546" height="1378" alt="WebMix method overview: a scout creates a domain manual, a hypernetwork mixes LoRA adapters, and a web agent uses the mixed adapter" decoding="async"></a></figure></div>
